# Trabalho-Design-Proficional

 Testes de Software

# Objetivo:
Este repositório reúne exemplos práticos de documentação de testes de software,
desenvolvidos como parte dos meus estudos em Análise e Desenvolvimento de Sistemas (ADS)
e como material de portfólio para candidaturas na área de QA/Testes.

O objetivo é demonstrar conhecimento prático em:
Elaboração de planos de teste
 Criação de casos de teste (test cases)
 Identificação e documentação de bugs
 Uso de controle de versão (Git/GitHub) em fluxo de trabalho colaborativo

# Estrutura do repositório
 `/planos-de-teste` — Planos de teste elaborados para funcionalidades específicas
 `/casos-de-teste` — Casos de teste detalhados (cenário, passos, resultado esperado)
 `/relatorios-de-bugs` — Exemplos de relatórios de bugs encontrados

# Tecnologias e ferramentas
 Git e GitHub para controle de versão
Markdown para documentação
 (adicione aqui outras ferramentas que você usar, ex: Trello, Postman, etc.)
